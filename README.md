# ArchStore BIM — o'rnatuvchi va yangilanishlar

Bu tarmoqda (`dist`) plaginning tarqatiladigan fayllari turadi. Plagin yangilanishni shu yerdan oladi, shuning uchun tarmoq nomi va fayl nomlari o'zgartirilmaydi.

| Fayl | Nima |
|---|---|
| `ArchStoreBIM-Setup.exe` | Yangi foydalanuvchilar uchun o'rnatuvchi (oxirgi versiya) |
| `version.json` | Oxirgi versiya haqida ma'lumot — plagin shu faylni tekshiradi |
| `ArchStoreBIM-<versiya>.zip` | Yangilanish paketi |

**O'rnatish:** `ArchStoreBIM-Setup.exe` ni yuklab, ishga tushiring (Revit 2024 va pyRevit kerak).

**Yangilash:** Revit'da ArchStore BIM > Sozlamalar > "Yangilanishni tekshirish".
