# ArchStore BIM

Revit 2024 uchun pyRevit kengaytmasi: model katalogi va loyihalash asboblari.

## O'rnatish

1. Revit 2024 va [pyRevit](https://github.com/pyrevitlabs/pyRevit/releases) o'rnatilgan bo'lsin.
2. O'rnatuvchini yuklab, ishga tushiring: **[ArchStoreBIM-Setup.exe](https://github.com/boburclash0272-byte/archstorebim/raw/dist/ArchStoreBIM-Setup.exe)**
3. Revit'ni oching — lentada "ArchStore BIM" tabi chiqadi.

Windows "noma'lum nashriyotchi" deb ogohlantirishi mumkin: "Подробнее" > "Выполнить в любом случае".

## Yangilash

Revit'da: ArchStore BIM > Sozlamalar > "Yangilanishni tekshirish".

## Asboblar

- **Katalog** — model kutubxonasi
- **Pol** — xonalarga pol yaratish
- **Listlar** — listlar yaratish va vidlarni joylash
- **Nomerator** — list raqamlarini o'zgartirish
- **Saqlash** — loyiha papkalari bilan birinchi saqlash
- **Avtosaqlash**
- **Sozlamalar** — mavzu, til, yangilanish

---

**Установка:** скачайте и запустите [ArchStoreBIM-Setup.exe](https://github.com/boburclash0272-byte/archstorebim/raw/dist/ArchStoreBIM-Setup.exe) (нужны Revit 2024 и pyRevit). **Обновление:** «Настройки» → «Проверить обновления».
