# ArchStore BIM — o'rnatuvchi va yangilanishlar

Bu tarmoqda (`dist`) plaginning tarqatiladigan fayllari turadi. Plagin yangilanishni shu yerdan oladi, shuning uchun tarmoq nomi va fayl nomlari o'zgartirilmaydi.

| Fayl | Nima |
|---|---|
| `ArchStoreBIM-Setup.exe` | O'rnatuvchi (oxirgi versiya) |
| `app.json` | Oxirgi versiya haqida ma'lumot — plagin shu faylni tekshiradi |
| `ArchStoreBIM-<versiya>.zip` | Yangilanish paketi |
| `version.json`, `ArchStoreBIM-0.9.0.zip` | Eski (pyRevit) versiyasi uchun — o'zgartirilmaydi |

**O'rnatish:** `ArchStoreBIM-Setup.exe` ni yuklab, ishga tushiring. Revit 2020–2027 da ishlaydi, pyRevit kerak emas.

**Akkaunt:** 0.26.0 dan boshlab dastur akkaunt bilan ishlaydi. Birinchi marta istalgan asbobni bosganda ro'yxatdan o'tish oynasi chiqadi; administrator tasdiqlagach asboblar ochiladi. Savollar uchun: @Bobur_architects_supportbot.

**Yangilash:** Revit'da ArchStore BIM > Sozlamalar > "Yangilanishni tekshirish". Yangi versiya Revit qayta ochilganda ishlaydi.
